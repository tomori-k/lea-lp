基本的な使い方

無線（Bluetooth）での接続

  1. 左右両方の電源スイッチを入れる（接続先とつながるのは左側です）
  2. 接続先（PC やスマートフォンなど）の Bluetooth 設定画面を開き、一覧に表示される「lea」を選んでペアリングする
  3. ペアリングが完了すると、そのままキーボードとして使えます。次回からは、電源を入れると自動で再接続します

ペアリングした接続先はプロファイルに登録されます。初期キーマップでは5つのプロファイル（BT_SEL 0〜4）が使えるので、複数の機器を登録して、レイヤー3のキーで切り替えて使えます。新しい機器とペアリングするときは、空いているプロファイルに切り替えてから、上記の手順を行ってください。

うまくつながらないときは、レイヤー4のペアリング解除キー（BT_CLR）で現在のプロファイルの登録を消し、接続先の Bluetooth 設定からも「lea」を削除してから、ペアリングし直してください。

  • 有線接続：USB-C ケーブルで接続先とつなぐと、有線キーボードとして使えます。
  • 充電：USB-C で充電します。ケーブルは付属しません。
  • キースイッチ：ソケット式（ホットスワップ）なので、はんだ付けなしで抜き差しできます。

キーマップの変更方法

lea のファームウェアは ZMK です。キーマップの変更には、ブラウザ上でキーマップを視覚的に編集できるツール「Keymap Editor」を使うのがおすすめです。設定リポジトリをフォークしておくと、Keymap Editor からそのまま編集・保存（コミット）でき、コミットをきっかけに GitHub Actions が新しいファームウェアを自動でビルドします。

  1. 設定リポジトリ（zmk-config-broccoli）を、自分の GitHub アカウントにフォークする
  2. Keymap Editor を開き、GitHub アカウントでログインして、フォークしたリポジトリへのアクセスを許可する
  3. リポジトリを選ぶとキーマップが表示されるので、画面上でキーを選んで割り当てを変更する
  4. 保存すると変更がリポジトリにコミットされ、GitHub Actions がファームウェアをビルドする
  5. ビルドの成果物から、.uf2 ファイルをダウンロードする
  6. lea を USB-C で PC につないでブートローダーのドライブを表示し、.uf2 ファイルをコピーすると書き込まれる
